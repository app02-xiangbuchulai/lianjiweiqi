# 🎮 联机围棋

**一款轻量、简洁的网页端联机围棋对弈系统**，支持多人在线匹配、实时落子、悔棋、认输、计时对局，无需下载客户端，浏览器打开即可对弈。

## 📖 项目简介

Online\-Go 是一套前后端分离的联机围棋对弈开源项目，专为围棋爱好者打造。摒弃繁琐部署与复杂操作，聚焦核心对弈体验，支持玩家实时联机对战、基础对局规则、对局状态管理等功能，可快速部署自用、二次开发。

项目严格遵循**围棋基础规则**，支持黑白交替落子、禁止自杀、提子、对局计时、胜负判定，适配新手日常对弈与小型对局场景。

## ✨ 核心功能

- **实时联机对弈**：支持两名玩家在线匹配对局，WebSocket 实时同步落子状态，无延迟交互

- **标准围棋规则**：实现基础围棋规则，黑白落子、提子、禁着点、自杀判定、回合交替

- **对局操作功能**：支持悔棋申请、同意/拒绝悔棋、认输、暂停对局、重新开局

- **计时对局模式**：支持自定义对局时长、读秒倒计时，模拟正式对局场景

- **对局状态展示**：实时显示当前落子方、剩余时间、对局进度、胜负结果

- **简洁UI界面**：极简棋盘设计，适配电脑浏览器，操作直观、无冗余功能

- **轻量化部署**：前后端分离架构，部署简单、资源占用低，支持本地/服务器部署

## 🛠️ 技术栈

### 前端

- 基础：HTML5 \+ CSS3 \+ JavaScript \(ES6\+\)

- 实时通信：WebSocket

- UI 样式：原生 CSS / Tailwind CSS（按需适配）

- 棋盘渲染：原生 Canvas / DOM 布局

### 后端

- 服务框架：Node\.js \+ Express / SpringBoot（可自定义）

- 实时服务：WebSocket 服务端支撑

- 数据存储：本地缓存 / MySQL（简易对局记录）

## 🚀 快速启动

### 环境依赖

- Node\.js ≥ 14\.x

- npm / yarn 包管理工具

- 主流浏览器（Chrome / Edge / Firefox）

### 本地部署步骤

**1\. 克隆项目**

```Plain Text
git clone https://github.com/xxx/online-go.git
cd online-go
```

**2\. 安装依赖**

```Plain Text
npm install
```

**3\. 启动后端服务**

```Plain Text
npm run server
```

**4\. 启动前端页面**

```Plain Text
npm run dev
```

**5\. 访问项目**

浏览器打开：`http://localhost:3000`

## 📋 对局规则说明

- 默认 19×19 标准围棋棋盘，可自定义 9×9 / 13×13 小棋盘

- 黑方先手，黑白双方交替落子，落子后自动切换回合

- 自动判定禁着点、自杀落子，违规落子无效并提示

- 支持单颗/多颗棋子提子，自动移除无气棋子

- 一方认输、超时、无棋可下则对局结束，判定胜负

- 悔棋需对方同意，单次对局可多次申请悔棋（可后台配置限制）
