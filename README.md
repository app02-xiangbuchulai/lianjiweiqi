联机围棋项目
一款支持多人实时联机对战的围棋桌面程序，实现标准围棋规则、在线匹配、胜负判定等核心功能。
📌 项目简介
本项目基于 Java 开发，采用客户端 - 服务器（C/S）架构，通过 Socket TCP 完成双向网络通信，支持局域网、公网两种环境下双人实时对弈；完整实现现代围棋全套基础逻辑，包含落子合法性校验、禁入点判定、提子、打劫防循环、终局自动数子判胜负，同时配套悔棋、认输、重开对局等交互功能。
客户端使用 Swing 实现可视化图形界面，棋盘、棋子、操作按钮、对局提示一体化展示；服务端采用多线程设计，可同时承载多组玩家独立对局，房间数据相互隔离互不干扰。
🛠️ 开发环境
编程语言：Java

GUI 图形框架：Swing
网络通信：原生 Socket TCP
JDK 适配版本：1.8 / 11
开发工具：IDEA / Eclipse
运行依赖：无第三方图形库，纯 JDK 原生 API 实现
✨ 核心功能
一、网络服务能力
独立服务端程序启动，多线程处理多路客户端连接，支持多房间同时在线对局
客户端输入服务端 IP 与端口即可建立长连接，支持局域网、公网两种联机场景
服务端统一转发对局消息，落子、悔棋、认输指令实时同步至对局双方
断线自动检测，玩家离线后自动终止对局并释放房间资源
二、双人实时联机对弈
黑白双方交替落子，任意一方落子后，双方棋盘同步刷新棋子状态
对局身份自动分配：先进入房间玩家执黑，后进入执白
对局全程状态同步，双方棋盘、剩余操作完全一致
三、完整标准围棋规则校验
落子边界校验：仅允许在棋盘交叉点落子
气与提子逻辑：自动计算单块棋子气数，无气棋子直接提除
禁入点判定：落子后无气且无法提子，判定禁入点，禁止落子
打劫规则：缓存打劫点位，禁止对方立刻提回，防止无限循环落子
四、对局交互操作
落子：鼠标点击棋盘交叉点放置对应颜色棋子
悔棋：单方发起悔棋申请，对方同意后撤回上一步棋子
认输：任意一方点击认输，直接结束对局并判定对手获胜
重新开局：对局结束后可一键清空棋盘，开启全新对局
五、终局胜负判定
双方确认结束对局后，程序自动区分活棋、死棋
自动统计双方领地、存活棋子数量，内置标准贴目计算
弹窗展示黑白双方最终分数，清晰输出对局胜负结果
六、可视化界面
19 路标准围棋棋盘画布，清晰绘制网格、星位标记
黑白棋子分层渲染，视觉区分明显
侧边操作面板：悔棋、认输、重开、结束对局功能按钮
底部状态提示栏：实时显示当前执棋方、对局状态、违规提示

🚀 运行教程
1. 启动服务端
使用 IDE 导入 Maven 项目，等待依赖加载完成
运行 server 包下服务启动主类
默认监听端口 8888，控制台输出启动成功提示即代表服务就绪
2. 启动客户端联机
运行 client 包下客户端启动类，弹出图形窗口
在连接框填写服务端 IP 与端口（本地测试填写 127.0.0.1:8888）
两台客户端成功连接同一房间后，即可开始双人围棋对局
