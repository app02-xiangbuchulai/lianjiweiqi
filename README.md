联机围棋
⚫️ 联机围棋
一款基于 WebSocket 实现的实时联机围棋对弈系统，原生实现标准围棋规则，支持双人在线对弈、实时落子、自动提子、打劫、禁着点判断，浏览器开箱即玩，无需安装客户端。
特点：纯正围棋规则、低延迟联机、轻量部署、界面简洁、适合学习与对战

📌 项目简介
本项目是一款轻量化网页联机围棋，完整复刻日常对弈的核心围棋逻辑，区别于普通五子棋、简易棋盘项目。专注围棋本身规则，支持两名玩家实时联网对弈，服务端统一校验落子合法性，保证对局公平、规则严谨。

🎯 围棋核心规则实现（重点）
本项目严格遵循标准围棋规则，而非简易落子：
•	气与提子：自动计算棋子气数，无气棋子立刻提掉，支持单颗、多颗整块提子
•	禁着点判断：禁止自杀落子，无气且无法提对方棋子的位置不可落子
•	打劫规则：支持打劫判重，禁止立刻回提，避免无限循环对局
•	黑白交替行棋：黑先白后，自动轮换行棋权限
•	对局状态锁：非行棋方无法落子，防止乱下、抢下

✨ 功能清单
•	19路标准围棋棋盘（可切换 9/13/19 路）
•	WebSocket 实时双人联机，落子同步无延迟
•	完整围棋规则校验（气、提子、禁着、打劫）
•	创建房间 / 输入房间号匹配对局
•	行棋提示、当前执棋方展示
•	悔棋申请、对方确认机制
•	认输、结束对局、重新开局
•	对局步骤记录，简易复盘功能

🎮 使用方式
1.	打开页面，点击【创建房间】生成房间号
2.	好友输入房间号【加入房间】
3.	双方就位后自动开始对局，黑方先行
4.	系统自动判定落子是否合规、自动提子、防打劫
5.	可随时发起悔棋、认输、重启对局
