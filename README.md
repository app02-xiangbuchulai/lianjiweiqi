# 联机围棋项目
一款支持多人实时联机对战的围棋桌面程序，实现标准围棋规则、在线匹配、胜负判定等核心功能。

## 📌 项目简介
本项目基于 Java 开发，采用客户端-服务器架构，支持局域网/公网联机双人对弈；完整实现落子、禁入点、提子、数子判断胜负、悔棋、认输等围棋基础逻辑。

## 🛠 开发环境
- 编程语言：Java
- 构建工具：Maven
- GUI 框架：Swing
- 网络通信：Socket TCP
- JDK 版本：1.8 / 11

## ✨ 核心功能
1. 服务端启动，支持多客户端同时连接
2. 双人实时联机，双方落子同步刷新棋盘
3. 标准围棋规则校验：禁着点、打劫、提子
4. 基础操作：落子、悔棋、认输、重新开局
5. 对局结束自动数子，判断黑白双方胜负
6. 简洁可视化棋盘界面，区分黑白棋子
